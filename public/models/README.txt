RobotExpressive.glb

Source:
https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive

Original model by Tomas Laulhe (Quaternius), released under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

The Three.js example asset includes modifications by Don McCurdy:
three facial expression morph targets, FBX2GLTF conversion, and material cleanup.
The source README recommends considering support for the original creator:
https://www.patreon.com/quaternius

The bundled GLB was verified byte-for-byte against the RobotExpressive.glb file
in the official Three.js repository at the source URL above.
